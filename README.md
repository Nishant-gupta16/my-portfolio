# Nishant Gupta — Portfolio

A responsive personal portfolio built with React and Vite.

## Run locally

```sh
npm install
npm run dev
```

## Verify a production build

```sh
npm run lint
npm run build
```

## Publish with Vercel

1. Push this project to a GitHub repository.
2. In Vercel, choose **Add New → Project** and import that repository.
3. Keep the detected Vite settings: build command `npm run build`, output directory `dist`.
4. Deploy. The resume PDF is in `public/` and is included automatically.

The project also works with other static hosts. Build it with `npm run build` and publish the generated `dist/` folder.

## Portfolio images

The hero portrait and project screenshots are stored in `public/` and are included in the production build. To replace them, use the same filenames: `nishant-gupta.png`, `project-knowyourmedicine.png`, `project-brahmastra.png`, and `project-taskmaster.png`.
